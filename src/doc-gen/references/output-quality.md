# 输出质量与一致性自检

## 路径与 Markdown

- 所有代码路径使用仓库根相对正斜杠形式。
- Markdown 标题层级稳定，不跳级；代码块添加语言标识。
- 不复制大段源码，只保留公开签名、极短示例、状态表和可检索入口。

## YAML 检查

- `doc_type` 为 `ai-module-spec`，`spec_version` 为 `"3.0"`。
- `feature_index` 必须是以稳定 snake_case 功能域名为 key 的 YAML mapping，最多 8 项；每个 key 下只包含 `entry` 和 `body_section`。禁止 YAML sequence/list（包括 `- entry` 列表项）。
- 每个 `entry` 是仓库根相对路径，可带真实 `#symbol`。
- 每个 `body_section` 能在正文“功能目录”中定位。
- `detail_sections` 只使用 `scope`、`contract`、`verification`、`risks`、`dependencies`、`diagnostics`、`data_flow`、`removal`。
- `scope`、`contract`、`verification` 必需；可选 key 与正文对应章节同步出现或同步省略。
- YAML 不承载范围清单、契约详情、症状、风险说明、命令清单或执行状态。

## 事实检查

- 不含 `caller` 或调用方的实现、状态、测试、回退、修改计划和排障步骤。
- 不含历史阶段、提交列表、实施进度和瞬时测试状态。
- Vue 组件已完整扫描 Props、Emits、Slots、Expose；没有公开项时写“无”。
- 每个核心功能事实链都能映射回真实代码入口、编排或状态、数据转换、直接公共依赖或公开结果和验证入口。
- 直接公共依赖来自目标模块真实引用与 provider 公开声明，只记录实际使用的最小契约。
- 诊断第一检查点、稳定结构化信号和下一验证入口真实存在；不得把第一检查点或信号宣称为根因。
- 实现、测试、上下文或旧文档冲突时，相关内容保留在“模块内事实冲突”，没有写成确定事实。

## 长度规则

- 正文没有最低行数，也没有硬编码通过阈值；只对重复、失焦或难以渐进读取的过长正文发出预警。
- 复杂模块 YAML 目标 50 至 80 行，硬上限 100 行。
- 超限时删除重复、下沉详情、合并功能域并删除低价值索引；不压缩真实路径，不提高上限。

## 验证入口

模块文档只记录稳定验证入口：

| 字段 | 要求 |
| --- | --- |
| 改动层级 | adapter、service、组件契约、交互或跨 owner 契约 |
| 检查入口 | 测试文件、项目命令、类型检查或人工验收入口 |
| 检查类型 | 单元、组件、集成、类型、lint 或人工 |
| 能证明 | 该入口长期稳定覆盖的行为 |
| 不能证明 | 该入口长期不能覆盖的范围 |
| 扩大条件 | 需要增加检查的跨层或跨 owner 变化 |
| 长期前提 | 稳定环境要求，不记录某次机器状态 |

`能证明` 与 `不能证明` 只描述验证入口的长期能力边界，不描述某次运行结论。不得在模块文档记录 `passed`、`failed`、`not_run`、`blocked`、人工待验收状态，或“本次任务已执行通过”“本次已经验证”“当前检查成功”“运行结果正常”等任何自然语言同义表达；这些表述即使放在 `不能证明` 中也不允许出现。测试文件只能证明预期与覆盖范围，不能证明当前实现符合预期或本次已经执行。

## 按需章节

- 没有真实直接公共依赖时省略“直接公共依赖”。
- 没有两层以上语义转换时省略“数据转换与责任分层”。
- 没有稳定模块内症状与第一检查点时省略诊断章节。
- 没有多阶段状态、错误映射或并发淘汰结果时省略状态矩阵。
- 没有独立可删除功能边界时省略删除与保留章节。
- 没有跨功能不变量时省略跨功能风险。

省略正文按需章节时，同步删除对应可选 `detail_sections` key。

## Mermaid

- 仅在关系比短列表或表格更易理解时使用小型 Mermaid 图。
- 多阶段链路按功能拆分，不生成覆盖全模块的巨型图。
- 图下补充少量事实说明；不确定关系不得画入。

## 已有文档更新

- 首次 v1/v2 到 v3 升级允许结构性迁移。
- v3 后续更新优先局部修改，保持无关章节不变。
- 内部重构或恢复既有契约且导航未失效时，允许“无需修改模块文档”。
- 不双写旧字段，不记录变更历史。

## 输出前检查

1. 解析 YAML，核对 v3 字段、固定 key 与体积预算。
2. 校验所有路径、可选 symbol、正文功能入口和语义章节可达。
3. 核对文件角色、调用方排除、事实来源用途和冲突处理。
4. 核对公开契约、直接公共依赖、诊断与验证证明范围。
5. 核对按需章节和 YAML key 同步。
6. 核对没有历史记录、瞬时状态、失效引用、无证据推断或大段源码。
7. 已有文档更新时，核对无关章节未被重写。

自检结果只在当前任务完成报告中说明，不写入模块文档。
