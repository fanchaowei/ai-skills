# Public Contract

## 原则

只提取开发人员使用模块时需要知道的公开输入输出。不要逐个解释内部私有函数。

## Vue 组件

公开输入：

- `props`
- `slots`
- 外部注入配置

公开输出：

- `emits`
- `defineExpose`
- 用户可观察的交互结果

## 页面模块

公开输入：

- 路由参数
- 查询参数
- 外部 store 状态
- 用户操作

公开输出：

- 页面展示结果
- 路由跳转
- 请求结果展示
- store 状态变化

## Pinia Store

公开输入：

- action 参数
- 初始化参数

公开输出：

- state
- getters
- action 返回值
- 状态副作用

## Composable

公开输入：

- 函数参数
- 配置项
- 依赖注入

公开输出：

- 返回的响应式状态
- 返回的方法
- 清理函数

## Service/API

公开输入：

- 方法参数
- 请求配置
- 环境配置

公开输出：

- 响应数据
- 错误行为
- 取消、重试或连接关闭能力

## 工具函数

公开输入：

- 函数参数
- 配置项

公开输出：

- 返回值
- 异常或边界行为

## 无法确认的信息

- 类型未显式声明时，写“代码中未显式声明”。
- 输出不明显时，说明可观察副作用。
