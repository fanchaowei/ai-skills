# Index Maintenance

## 目标

维护对应 `docs/README.md`，让开发人员可以从入口快速找到模块开发使用文档。

## 默认格式

```markdown
# 开发文档

## 模块开发使用文档

| 模块 | 说明 |
|------|------|
| [中文模块名](modules/中文模块名.md) | 一句话说明模块用途 |
```

## 更新规则

- `docs/README.md` 不存在时创建。
- 模块索引项不存在时新增。
- 模块索引项已存在时更新说明。
- 模块索引链接必须指向 `docs/modules/` 下的简体中文文件名。
- 保留 README 中非模块索引区域的有效内容。
- 如果索引项指向不存在文件，最终报告中说明该项需要人工确认。
