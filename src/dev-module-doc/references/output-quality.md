# Output Quality

## 完成前自检

生成结束前检查：

- 文档落点是否正确。
- 是否说明模块功能清单。
- 是否说明使用方式。
- 是否包含最小使用示例。
- 是否列出公开输入。
- 是否列出公开输出。
- 是否列出主要依赖。
- 是否包含常见修改入口。
- 是否说明注意事项。
- 是否更新 `docs/README.md`。

## 禁止行为

- 不编造不存在的 API。
- 不编造不存在的类型。
- 不编造不存在的参数或返回值。
- 不把内部实现写成完整代码导读。
- 不把文档写入 `claudedocs/`。
- 不要求 Vue 2.7 项目支持 Vuex。

## 最终报告

最终回复包含：

- 模块文档路径。
- 索引路径。
- 模块类型。
- 是否找到真实使用方。
- 无法自动确认的信息。
