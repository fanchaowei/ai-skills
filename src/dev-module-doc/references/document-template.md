# Document Template

## 输出语言

默认使用中文，采用简洁直接的工程说明风格。

## 默认结构

```markdown
# 模块名

## 模块概览

一句话说明模块职责。

## 功能清单

- 功能 1
- 功能 2

## 使用方式

给出最小可参考示例。

## 公开输入

| 名称 | 类型 | 必填 | 说明 |
|------|------|------|------|

## 公开输出

| 名称 | 类型 | 说明 |
|------|------|------|

## 主要依赖

| 依赖 | 用途 |
|------|------|

## 设计逻辑

只说明对使用和修改有帮助的主流程，不展开所有内部私有函数。

## 常见修改入口

| 修改目标 | 入口位置 | 说明 |
|----------|----------|------|

## 注意事项

- 使用限制。
- 已知边界。
- 错误处理约定。
- 不确定点。
```

## 示例要求

使用方式必须包含最小示例。示例必须基于真实导出或真实组件契约，不编写“真实使用方示例”，也不要为了示例专门搜索或引用仓库中的调用方。

## 长度控制

默认控制在 2-4 屏。复杂模块可以略长，但不要写成完整源码导读。
